## 0. What is actually broken, and what this work order changes

There are three independent defects in the 0.2.2 tree. Fix them in three commits (three pull requests if you publish).

1. **The Metal decode window ignores RoPE scaling.** `src/program/generate.cpp` resolves `--rope-scaling` and the
   model file's rope keys, validates them, calls `rope_scaling_set()`, and logs the resolved config. But
   `metal/src/engine/window.cpp` never reads that config: it builds a fixed, unscaled cos/sin table with a `pow` call
   per position. `metal/src/engine/rope_table.h` (the builder that applies linear/YaRN) does not exist in 0.2.2.
   Result: a 512K run says "rope scaling yarn" and then decodes with the trained 262K angles. Contexts past 32,768
   degrade, and contexts past 262,144 are not actually extended.
2. **The host memory guard has no macOS branch.** `src/core/conversation_memory.cpp` handles Windows and Linux and
   returns "unknown" everywhere else. On macOS the non-Metal memory guard fails closed, so admission decisions cannot
   be made from real free memory.
3. **The Metal engine silently accepts K/V formats it cannot run.** `generate.cpp` accepts `--kv q4_0` and `--kv k8v4`
   on every backend, but the Metal decode window has one layout: int8. The flag is accepted, the global is set, and
   the Metal window ignores it. A user asking for q4_0 gets int8 without being told.

This work order also gives you the machine-local run configurations that replace the old
`/Volumes/vl/ai/Strata/strata-iq3_s-512k.json` and `/Volumes/vl/ai/Strata/strata-iq3_s.json`, and the hardware gates
that prove the fixes on this Mac.

**Not in scope, and do not bundle it into these changes:**

- Swift support in the 0.2.2 Mac installer (`metal/setup_mac.py`, `strata_control/mac_fit.py`). It is missing; see
  section 10. Use the hand-written run configs in section 8 instead.
- The `serve/test_lifeline.py` watcher failure. It fails on the unmodified tree; it is a separate issue.
- New defaults (context, `--spec`, K/V format, keep-free reserve). The default path must stay byte-identical.
- Kernel changes (`metal/kernels/*.metal`, `qsa.metal`, `metal/src/engine/window.cpp`'s dispatch graph).
- 1M-token context. 512K is the target; 1M is not tested here.
- `switch.sh` / `monitor.py`. They do not exist in 0.2.2 and must not be resurrected.
- Cross-backend builds. This Mac has no CUDA, HIP, or SYCL toolchain. Mark them "not run" and say why.

## 2. Rules for every change

Read `AGENTS.md` and `CONTRIBUTING.md` before the first edit. Then follow these rules:

1. **One problem per commit.** The RoPE change, the Apple memory change, and the Metal K/V guard are three commits.
   Do not combine them "while you are there."
2. **The default path stays byte-identical.** With no rope flags and no rope keys, the new Metal table must equal the
   old fixed table bit for bit. `rope_parity` is the proof. Do not change a default to make a test easier.
3. **No default changes.** Context, `--spec`, `--kv`, `--expert-cache`, `STRATA_METAL_KEEP_FREE_GB`, and the frozen
   arena numbers stay as they are. The run configs in section 8 are explicit choices, not new defaults.
4. **Do not edit `arena_budget_test.cpp`.** The freeze is 137.4 GB RAM / 115.4 GB working set / 97.7 GB available.
   Do not refreeze from the nominal 128 GiB.
5. **Do not create `switch.sh` or `monitor.py`.** 0.2.2 uses `strata launch`, `serve/server.py`, and `strata monitor`.
   `serve/server.py:_authorized` already accepts both header forms.
6. **Do not commit** model files, packs, `third_party/llama.cpp`, `build-*`, `logs/`, `strata-*.json`, `.DS_Store`, or
   the three working documents (`v0.2.2-m5-migration-report.md`, `v0.2.2-m5-implementation-plan.md`, this file).
   The run configs are root-level `strata-*.json` and are already gitignored.
7. **Use `/Volumes/vl/ai/.venv/bin/python`.** The system `python3` fails on `serve/test_security.py` because `jinja2`
   is missing.
8. **Do not run two model servers at once.** The Swift 512K server holds tens of GB. Stop the old port-8000 server
   before starting the new one, and stop the new one before running a test that loads the model directly.
9. **Never expose the server beyond `127.0.0.1` without an API key.** The configs in this document use loopback and
   an empty key.
10. **Do not claim a run you did not perform.** "Passed", "failed", and "not run (reason)" are three separate lists in
    every report. A test from reading code is "unconfirmed static analysis," not "passed."
11. **Stop on a failed gate.** Report the command, the exit code, and the first relevant log lines. Do not paper over
    it with a retry, a flag change, or a test edit.

### 4.1 Create `metal/src/engine/rope_table.h`

Create the file with exactly this content. It is the old tree's builder, unchanged; it is header-only and inline.

```cpp
#pragma once

#include "strata/kernels/rope_scaling.hpp"
#include <cmath>
#include <cstddef>
#include <vector>

namespace strata::metal_engine {

namespace detail {

// The table's math, written once and shared by every layout, so the decode window and the parity test
// cannot drift apart.  Writer(p, i, cos, sin) receives the float32 pair for that entry.
//
// `inv` depends only on the pair index, so it is computed once per table rather than once per entry:
// at a 524,288-token context the window builds 524,368 positions x 32 pairs, and recomputing it per
// entry would be 16.8 M std::pow calls for a value that is one of 32.  The angle itself still depends
// on the position, so the trig stays in the loop.
template <class Writer>
inline void rope_table(int n_rot, const strata::kernels::RopeScaling& sc, int max_pos, Writer&& w) {
    const int half = n_rot / 2;
    std::vector<double> inv((size_t) half);
    for (int i = 0; i < half; ++i) inv[(size_t) i] = std::pow(sc.freq_base, -2.0 * (double) i / (double) n_rot);

    if (sc.type == strata::kernels::RopeScalingType::None) {
        for (int p = 0; p < max_pos; ++p)
            for (int i = 0; i < half; ++i) {
                const double ang = (double) p * inv[(size_t) i];
                w(p, i, (float) std::cos(ang), (float) std::sin(ang));
            }
        return;
    }

    const double fs = sc.freq_scale();
    const double ms = sc.mscale();
    double cd[2];
    sc.corr_dims(n_rot, cd);
    const bool correct = sc.ext_factor != 0;
    for (int p = 0; p < max_pos; ++p)
        for (int i = 0; i < half; ++i) {
            const double extrap = (double) p * inv[(size_t) i];
            const double interp = fs * extrap;
            double ang = interp;
            if (correct) {
                const double ramp = (double) strata::kernels::rope_yarn_ramp((float) cd[0], (float) cd[1], i) * sc.ext_factor;
                ang = interp * (1.0 - ramp) + extrap * ramp;
            }
            w(p, i, (float) (std::cos(ang) * ms), (float) (std::sin(ang) * ms));
        }
}

}  // namespace detail

// The trained angles, exactly: the same table the CUDA/HIP/SYCL host builders produce.
inline void build_rope_table(int n_rot, double theta, int max_pos, float* cos_tab, float* sin_tab) {
    strata::kernels::RopeScaling sc;
    sc.freq_base = theta;   // type None: no scaling, no magnitude correction
    const int half = n_rot / 2;
    detail::rope_table(n_rot, sc, max_pos, [&](int p, int i, float c, float s) {
        cos_tab[(size_t) p * half + i] = c;
        sin_tab[(size_t) p * half + i] = s;
    });
}

// The same table with a resolved scaling (none, linear or yarn) folded into the cos/sin contents.
inline void build_rope_table(int n_rot, const strata::kernels::RopeScaling& sc, int max_pos, float* cos_tab, float* sin_tab) {
    const int half = n_rot / 2;
    detail::rope_table(n_rot, sc, max_pos, [&](int p, int i, float c, float s) {
        cos_tab[(size_t) p * half + i] = c;
        sin_tab[(size_t) p * half + i] = s;
    });
}

// The decode window's layout: float2 [pos][half], (cos, sin) interleaved, which is what the MSL
// kernels read out of `cs_`.  Built in place: the window has the destination in hand, and staging it
// planar first would cost 134 MB of transient host memory at a 524,288-token context for nothing.
inline void build_rope_table_interleaved(int n_rot, const strata::kernels::RopeScaling& sc, int max_pos, float* dst) {
    const int half = n_rot / 2;
    detail::rope_table(n_rot, sc, max_pos, [&](int p, int i, float c, float s) {
        dst[((size_t) p * half + i) * 2] = c;
        dst[((size_t) p * half + i) * 2 + 1] = s;
    });
}

}  // namespace strata::metal_engine
```

Create the file with exactly this content:

```cpp
// metal/tests/rope_parity.cpp - Metal host-side RoPE table parity test.
// Verifies float64 reference trig and RopeScaling (none, linear, YaRN) against
// the Metal engine's inline build_rope_table implementation in engine/rope_table.h.

#include "engine/rope_table.h"
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <string>
#include <vector>

int main(int argc, char** argv) {
    bool selftest = false;
    for (int i = 1; i < argc; ++i) {
        if (std::string(argv[i]) == "--selftest") selftest = true;
        else { std::fprintf(stderr, "usage: rope_parity [--selftest]\n"); return 2; }
    }

    const int n_rot = 64;          // dimension_count
    const double theta = 1.0e7;    // freq_base
    const int max_pos = 32;
    const int half = n_rot / 2;
    int bad = 0;

    // ---- 1. Unscaled table against float64 reference
    std::vector<float> hcos((size_t) max_pos * half), hsin((size_t) max_pos * half);
    strata::metal_engine::build_rope_table(n_rot, theta, max_pos, hcos.data(), hsin.data());
    long long table_bad = 0;
    double table_worst = 0.0;
    for (int p = 0; p < max_pos; ++p) {
        for (int i = 0; i < half; ++i) {
            const double inv = std::pow(theta, -2.0 * (double) i / (double) n_rot);
            const double ang = (double) p * inv;
            const float rc = (float) std::cos(ang), rs = (float) std::sin(ang);
            if (std::memcmp(&rc, &hcos[(size_t) p * half + i], 4) != 0) ++table_bad;
            if (std::memcmp(&rs, &hsin[(size_t) p * half + i], 4) != 0) ++table_bad;
            table_worst = std::max(table_worst, std::fabs((double) rc - (double) hcos[(size_t) p * half + i]));
        }
    }
    std::printf("  unscaled rope table vs float64 reference   %s (%lld of %d entries differ, worst %.1e)\n",
                table_bad ? "*** WRONG ***" : "bit-exact", table_bad, max_pos * half * 2, table_worst);
    bad += (int) table_bad;

    // ---- 2. Scaled table (None vs unscaled overload)
    std::vector<float> nc((size_t) max_pos * half), ns((size_t) max_pos * half);
    strata::kernels::RopeScaling none;
    none.freq_base = theta;
    strata::metal_engine::build_rope_table(n_rot, none, max_pos, nc.data(), ns.data());
    const long long none_bad = (long long) (std::memcmp(nc.data(), hcos.data(), nc.size() * 4) != 0) +
                               (long long) (std::memcmp(ns.data(), hsin.data(), ns.size() * 4) != 0);
    std::printf("  scaled table (type None) vs unscaled       %s\n", none_bad ? "*** WRONG ***" : "bit-identical");
    bad += (int) none_bad;

    // ---- 3. Linear scaling (factor 4)
    strata::kernels::RopeScaling lin;
    lin.type = strata::kernels::RopeScalingType::Linear;
    lin.freq_base = theta;
    lin.factor = 4.0;
    std::vector<float> lc((size_t) max_pos * half), ls((size_t) max_pos * half);
    strata::metal_engine::build_rope_table(n_rot, lin, max_pos, lc.data(), ls.data());
    long long lin_bad = 0;
    for (int p = 0; p < max_pos; ++p) {
        for (int i = 0; i < half; ++i) {
            const double inv = std::pow(theta, -2.0 * (double) i / (double) n_rot);
            const double ang = (double) p * inv / 4.0;
            const float rc = (float) std::cos(ang), rs = (float) std::sin(ang);
            if (std::memcmp(&rc, &lc[(size_t) p * half + i], 4) != 0) ++lin_bad;
            if (std::memcmp(&rs, &ls[(size_t) p * half + i], 4) != 0) ++lin_bad;
        }
    }
    std::printf("  scaled table (Linear factor 4)            %s (%lld of %d entries differ)\n",
                lin_bad ? "*** WRONG ***" : "bit-exact", lin_bad, max_pos * half * 2);
    bad += (int) lin_bad;

    // ---- 4. YaRN scaling (factor 4)
    strata::kernels::RopeScaling yarn;
    yarn.type = strata::kernels::RopeScalingType::YaRN;
    yarn.freq_base = theta;
    yarn.factor = 4.0;
    yarn.ext_factor = 1.0;
    std::vector<float> yc((size_t) max_pos * half), ys((size_t) max_pos * half);
    strata::metal_engine::build_rope_table(n_rot, yarn, max_pos, yc.data(), ys.data());
    const double fs = yarn.freq_scale();
    const double ms = yarn.mscale();
    double cd[2];
    yarn.corr_dims(n_rot, cd);
    long long yarn_bad = 0;
    for (int p = 0; p < max_pos; ++p) {
        for (int i = 0; i < half; ++i) {
            const double inv = std::pow(theta, -2.0 * (double) i / (double) n_rot);
            const double extrap = (double) p * inv;
            const double interp = fs * extrap;
            const double ramp = (double) strata::kernels::rope_yarn_ramp((float) cd[0], (float) cd[1], i) * yarn.ext_factor;
            const double ang = interp * (1.0 - ramp) + extrap * ramp;
            const float rc = (float) (std::cos(ang) * ms), rs = (float) (std::sin(ang) * ms);
            if (std::memcmp(&rc, &yc[(size_t) p * half + i], 4) != 0) ++yarn_bad;
            if (std::memcmp(&rs, &ys[(size_t) p * half + i], 4) != 0) ++yarn_bad;
        }
    }
    std::printf("  scaled table (YaRN factor 4)              %s (%lld of %d entries differ)\n",
                yarn_bad ? "*** WRONG ***" : "bit-exact", yarn_bad, max_pos * half * 2);
    bad += (int) yarn_bad;

    // ---- 5. The decode window's interleaved layout, against the planar tables above
    std::vector<float> ic((size_t) max_pos * half * 2), iy((size_t) max_pos * half * 2);
    strata::metal_engine::build_rope_table_interleaved(n_rot, none, max_pos, ic.data());
    strata::metal_engine::build_rope_table_interleaved(n_rot, yarn, max_pos, iy.data());
    long long ilv_bad = 0;
    for (int p = 0; p < max_pos; ++p) {
        for (int i = 0; i < half; ++i) {
            const size_t e = (size_t) p * half + i;
            if (std::memcmp(&ic[e * 2], &hcos[e], 4) != 0) ++ilv_bad;
            if (std::memcmp(&ic[e * 2 + 1], &hsin[e], 4) != 0) ++ilv_bad;
            if (std::memcmp(&iy[e * 2], &yc[e], 4) != 0) ++ilv_bad;
            if (std::memcmp(&iy[e * 2 + 1], &ys[e], 4) != 0) ++ilv_bad;
        }
    }
    std::printf("  interleaved layout (None, YaRN) vs planar  %s (%lld of %d entries differ)\n",
                ilv_bad ? "*** WRONG ***" : "bit-identical", ilv_bad, max_pos * half * 4);
    bad += (int) ilv_bad;

    std::printf("\nrope: %d failures\n", bad);
    if (bad) return 1;
    if (selftest) std::printf("rope_parity OK\n");
    return 0;
}
```

std::optional<HostMemoryReading> sample_host_memory() {
#if defined(_WIN32)
    MEMORYSTATUSEX status{};
    status.dwLength = sizeof status;
    // #1607: the commit limit (RAM + page file) refuses an allocation while physical RAM is still free
    if (!GlobalMemoryStatusEx(&status)) return {};
    return combine(std::min<uint64_t>(status.ullAvailPhys, status.ullAvailPageFile), status.ullTotalPhys, CgroupScan{}, memory_limit_bytes());
#elif defined(__linux__)
    return sample_host_memory(MemoryProbePaths{}, memory_limit_bytes());
#elif defined(__APPLE__)
    uint64_t phys = 0;
    size_t len = sizeof phys;
    if (sysctlbyname("hw.memsize", &phys, &len, nullptr, 0) != 0 || phys == 0) return {};
    vm_statistics64_data_t vs{};
    mach_msg_type_number_t count = HOST_VM_INFO64_COUNT;
    if (host_statistics64(mach_host_self(), HOST_VM_INFO64, (host_info64_t) &vs, &count) != KERN_SUCCESS) return {};
    const double page = (double) vm_page_size;

    const double inactive_b = (double) vs.inactive_count * page;

#endif
