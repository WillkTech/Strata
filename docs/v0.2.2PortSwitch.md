  ## 2. Root Cause Analysis (Port Switching & Freeze)

  1. Missing Preset Ownership: strata monitor launched without --url ran as a local
  standalone monitor, but passed an empty info dict. Consequently, _preset_name() returned
  None and _can_write_port() evaluated to False.
  2. Model Name vs ID Mismatch: Telemetry reported model = "Swift-1.5-...", whereas
  discover_models() keyed configurations by id = "strata-m5-64k.json". Exact matching failed
  (model = None), preventing model resolution.
  3. Dead-End Server Restart: In _perform_port_change, when model failed resolution, the old
  server PID was terminated, but relaunch was aborted silently.
  4. Unsynchronized Preset on Disk: Configuration files (strata-*.json in state directory)
  and runtime profiles were not updated on disk before the restart was issued.
  5. Direct Dataclass Instantiation: LaunchSettings(port="") bypassed dictionary validation;
  adding __post_init__ ensures coercion regardless of instantiation path.
